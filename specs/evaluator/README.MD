# Evaluator (EVL)

Status: **first draft.** Also bound by the common requirements COM-ISL, COM-ISO, COM-ID, COM-DET, COM-RES, COM-LOC, COM-PRV, COM-FLT and COM-INP in [`specs/common`](../common/README.MD).

## Purpose

Score the user's answers and produce feedback and the session report. Not latency-sensitive.

## Boundary

**Takes in**

- The full transcript, by turn, with each piece's confidence
- Interview context: role, resume, job description, stage
- The session's conditions: simulation preset, cue mode, interface (voice or text), and which accommodations were used
- The event stream, for turn-taking measures
- A rubric, identified and versioned

**Puts out**

- A score and feedback for each answered question
- Turn-taking measures
- The session report

**Not this layer's job:** anything during the live turn. It is never on the critical path.

## Requirements

### Scoring

- **EVL-SCO-001** For each answered question, the layer MUST give a score and feedback, and the feedback MUST point to the part of the answer it relies on.
- **EVL-SCO-002** The rubric used MUST be identified, with its version, and MUST stay the same for the whole session.
- **EVL-SCO-003** Scores for the same transcript and rubric SHOULD be similar across repeated runs. The spread MUST be measurable.
- **EVL-SCO-004** For questions about past behavior, the layer SHOULD say which parts of a situation-task-action-result structure are present and which are missing.
- **EVL-SCO-005** The layer MUST handle a session that ended early or has unanswered questions, and MUST say which questions were not scored.

### Fairness

- **EVL-FAI-001** The layer MUST NOT lower a score because the user used an accommodation: captions, push-to-talk, a hold ("give me a sec"), or switching to text.
- **EVL-FAI-002** Where the transcript was uncertain, or the audio was degraded by a simulated condition, the layer MUST account for it. It MUST NOT penalize content that may have been lost to transcription or conditions, and MUST flag the affected answers.
- **EVL-FAI-003** The layer MUST NOT base a score on the user's voice, accent, name or any protected characteristic. Scores concern content and communication only.

### Turn-taking

- **EVL-TRN-001** The layer MUST measure, from the event stream, interruptions, overlong silences and clarification requests after clipped or lost audio, and MUST report them separately from answer scores.

### Report

- **EVL-REP-001** The report MUST record the conditions of the session: simulation preset, cue mode, interface, and the implementations and versions used.
- **EVL-REP-002** The report MUST separate what was measured (times, counts) from what was judged (answer quality), and MUST state that judgments are generated by a model and can be wrong.
- **EVL-REP-003** The report MUST NOT present a score as a prediction of hiring outcomes.
- **EVL-REP-004** Anything in the report that draws on the user's speech MUST be treated as personal data (COM-PRV-001).

### Timing

- **EVL-TIM-001** The layer MAY run after the session or between turns, and MUST NOT delay the live interview.

## Out of scope for now

Scoring for the behavioral de-escalation practice mode. It is highly subjective, and `ROADMAP.MD` section 2 holds it back until research shows whether observable feedback is feasible.

## Targets (provisional, to be set from prototype measurements)

| ID | Measure | Starting point |
|---|---|---|
| EVL-TGT-001 | Agreement with scores given by people on the same transcripts | to be set (a benchmark) |
| EVL-TGT-002 | Spread of scores across repeated runs | to be set |
| EVL-TGT-003 | Time to produce a report for a 45-minute session | to be set |

## Conformance vectors (planned)

1. A transcript scored twice with one rubric: both runs identify the rubric, the spread is measurable (EVL-SCO-002, EVL-SCO-003).
2. A session that ended after three questions (EVL-SCO-005).
3. The same answers with and without captions and holds in the session log: scores do not drop (EVL-FAI-001).
4. A garbled transcript from a degraded-audio session: answers flagged, not penalized (EVL-FAI-002).
5. Two transcripts with the same content from different named users: same score (EVL-FAI-003).
6. An event stream with interruptions and long silences: reported separately (EVL-TRN-001).
7. A report: conditions present, judged and measured parts separated, no hiring prediction (EVL-REP-001 to EVL-REP-003).

## Running alone

Feed a recorded session (transcript, context, conditions, event stream). Capture the report. Compare to scores given by people in benchmarking.

## Assumptions about neighbouring layers

- The transcript marks which pieces were uncertain and which audio was degraded (STT-FAI-004, EVT-TYPE-008).
- The session reports which accommodations were used.

## Open questions

1. How the rubric is authored and versioned, and where it lives.
2. Whether the evaluator may use a stronger model than the interview needed, and what that costs on a small machine.
3. How feedback is worded so it helps without implying certainty it does not have.
