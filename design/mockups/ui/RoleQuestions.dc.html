Role focus: where the questions come from

A role needs questions, and the AI writing them is the default, so the question is answered unless the user changes it. States 1 to 3 are the three starting cases. States 4 to 6 are what the user can change. Uploads never stop the user; the waiting room finishes them. This panel is on the Role set up page, under the job description.

How the user gets in

For an existing role, the questions setup opens from a Setup questions button. It appears once a Role title is chosen, and it is disabled while the app checks whether the role already has questions. A new role goes straight to the panel after its job description is added.

What the button opens

State 1

New role

Role: new · questions: default

No roles are saved, or the user adds another. They upload the job description and the new role is selected for them. The upload does not stop anything. The questions panel opens straight away, with the AI writing the questions as the default.

Uploading the job description. You can keep going; the waiting room finishes it.

Interview questions

This is a new role, so it has no questions yet.

Enabled. Uploads do not stop you.
State 2

Existing role, no questions

Role: existing · questions: missing

The user pressed Setup questions for a saved role that has none. The AI writing them is already selected, so nothing has to be chosen.

Interview questions

[ROLE TITLE] has no saved questions yet.

Enabled.
State 3

Existing role, has questions

Role: existing · questions: saved

The user pressed Setup questions for a saved role that already has questions. Keeping them is the default, so nothing is deleted by accident.

Interview questions

[ROLE TITLE] already has [N] saved questions. Do you want to purge them?

Enabled.
State 4

Upload chosen, no file yet

Questions: upload · no file

The user chose to upload their own questions but has not picked a file. This is the one questions state that stops Prepare, because there is nothing to upload.

Interview questions

Disabled until you choose a questions file, or switch back to the AI.
State 5

Uploading my own questions

Questions: upload · uploading

The questions file is uploading. It does not stop anything. The waiting room finishes the upload and reads the questions.

Interview questions

Processing [QUESTIONS FILE NAME]. This can take a moment.
Enabled. The upload does not stop you.
State 6

Purge chosen

Role: existing · questions: purge

The user chose to purge the saved questions. The warning says what is lost and when. The AI writing the new ones is already selected.

Interview questions

Purging deletes the [N] saved questions for [ROLE TITLE]. This cannot be undone. They are removed when you press Prepare interview.
