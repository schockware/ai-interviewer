Hot interview: the resume panel

What opens under Interview type when Hot is selected, in each state of ResumeValidation. Prepare interview stays disabled until the form is a complete hot interview.

State 1

Hot selected, no saved resumes

ResumeValidation: { type: "hot-incomplete=>cold" }

You switch to Hot and have never loaded a resume. The saved-resume picker is hidden because there is nothing to pick. A resume must be loaded.

Load a resume (required for a hot interview)

A hot interview needs a resume. Pick or load one, or switch to a cold interview. If this form were ever submitted without one, the interview would fall back to a cold interview.

Disabled until a resume is loaded. A role focus is also needed.
State 2

Resume processing

ResumeValidation: { type: "hot-incomplete=>cold" }

The file is uploading and being processed. The form stays in the incomplete state, kept as local state, until the server returns ResumeProcessed.

Load a resume (required for a hot interview)
Processing [RESUME FILE NAME]. This can take a moment.

A hot interview needs a resume. Pick or load one, or switch to a cold interview. If this form were ever submitted without one, the interview would fall back to a cold interview.

Disabled while the resume processes.
State 3

Resume processed

ResumeValidation: { type: "hot", resumeId }

The server returned ResumeProcessed. The new resume is selected automatically and the form becomes a hot interview.

Newest first. The resume you just loaded is selected.
Load a resume (required for a hot interview)
[RESUME DISPLAY NAME] is loaded and selected.
Ready once a role focus is chosen.
State 4

Hot selected, saved resumes

ResumeValidation: { type: "hot", resumeId }

You switch to Hot and already have saved resumes. The last one you picked is selected for you, so the form is a hot interview straight away.

Newest first. Starts on the last resume you picked if it still exists, otherwise the most recent.
Load a resume (required for a hot interview)
Ready once a role focus is chosen.
