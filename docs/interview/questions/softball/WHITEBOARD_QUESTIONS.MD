# Whiteboard-Heavy System Design Questions
• "Design a distributed web crawler that can discover and index billions of web pages while respecting robots.txt and avoiding duplicate URLs."
• "How would you design a real-time collaborative document editing system like Google Docs? Focus on how you handle write conflicts when two users edit the same line simultaneously."
• "Design the backend architecture for a live video streaming platform like Twitch, scaling from a single broadcaster to millions of concurrent viewers globally."
• "How would you architect a global asset tracking system for a logistics company with 500,000 active delivery vehicles sending GPS coordinates every 5 seconds?"
• "Design a scalable, highly available notification service capable of sending transactional emails, SMS, and push notifications to 100 million users."
